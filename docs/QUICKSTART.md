# Quick Start Guide

Get up and running with Mother-Root in 5 minutes.

## 1. Installation

```bash
git clone https://github.com/lezkt1811-maker/Mother-Root.git
cd Mother-Root
npm install
```

## 2. First Run

```bash
npm start
```

You should see:
```
Mother-Root initialized
```

## 3. Run Tests

```bash
npm test
```

## 4. Development Mode

For active development with auto-reload:

```bash
npm run dev
```

## Troubleshooting

### Issue: Module not found

**Solution:** Make sure you've run `npm install`

### Issue: Port already in use

**Solution:** Change the port in `config/example.json`
